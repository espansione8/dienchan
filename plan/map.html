DIENCHAN structuremap

App Structure Map

SvelteKit 5 portal for the Italian Dien Chan facial reflexology association: membership signup/renewal, practitioner directory, course and event catalogue with certificate generation, product e-commerce shop with Stripe payments, order and discount administration, and role-gated dashboards for users, formatori (trainers), riflessologi, admins and superadmins on MongoDB/Mongoose plus a small Drizzle SQLite messages table. key relationships

products ─▸ layouts
Product.layoutId → Layout.layoutId via virtual layoutView (justOne). Used to render course template title/bgColor/price in course-shop and course-table.
orders ─▸ users
Order.userId → User.userId via virtual userView (justOne). Populated in order fetches to show buyer name/email/city.
products ─▸ users
Product.userId → User.userId (creator/trainer). Not a Mongoose virtual but logical FK for scoping course-table by trainer.
products.listSubscribers ─▸ users
Product.listSubscribers[].userId references users.userId; certification fields updated via arrayFilters $[elem].
videos.visibility ─▸ users.level
Video.visibility array $in User.level gating for tutorial access (Navbar getVideosByLevel).
discounts.prodId ─▸ products.prodId
Discount.prodId targets product-specific discounts applied at cart checkout (selectedApplicability prodId with qty threshold).
discounts.layoutId ─▸ layouts.layoutId
Discount.layoutId targets layout/template discounts.
discounts.referral ─▸ users.email
Discount.referral holds trainer email; checkout awards refPoints % of totalValue to that user and sends mail.

.env
All values loaded at boot. REQUIRED keys must be present; OPTIONAL keys enable secondary features.
required core · payments · mailer
BASE_URLrequiredInternal base URL for server-to-server fetch calls to /api/mongo/* and /api/mailer/* (e.g. https://associazione.riflessologiadienchan.it or http://localhost:5173)
APIKEYrequiredShared secret for /api/mongo/* and /api/mailer/* POST gate (timingSafeEqual). Redacted value in src/routes/api/mongo/* and hooks.server.ts
MONGO_URIrequiredMongoDB connection string for mongoose (src/lib/server/mongo/database.ts). Error if missing.
SALTrequiredSalt concatenated before SHA-256 password hashing (src/lib/tools/hash.ts, login/membership-new).
STRIPE_KEY_FRONTrequiredStripe publishable key for client @stripe/stripe-js init (exposed to load payload).
STRIPE_KEY_BACKrequiredStripe secret key for server Stripe SDK (src/routes/(app)/cart/+page.server.ts etc).
STRIPE_APIrequiredStripe API version string passed as apiVersion to new Stripe(...).
MAILER_HOSTrequiredSMTP host for nodemailer transport (all /api/mailer/*).
MAILER_PORTrequiredSMTP port (numeric, parsed via Number).
MAILER_USERrequiredSMTP auth user.
MAILER_PASSrequiredSMTP auth password (value redacted).
PUBLIC_BASE_URLrequiredPublic base URL for client assets (pdfValue certificate backgrounds /training/*.jpg) via $env/static/public.
optional mailer · database
MAILER_SECUREoptionalWhether to use TLS (==='true' → true, else false). Undefined treated as false.
SQLITE_DB_PATHoptionalSQLite file path (commented out, intended ./data/sqlite.db) for Drizzle; currently not wired.
BACKUP_DIRoptionalBackup directory for SQLite (commented in backup.ts).
